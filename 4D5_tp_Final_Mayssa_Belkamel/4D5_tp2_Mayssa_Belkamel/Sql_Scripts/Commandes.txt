2) Installation de Evolve Tool  (si à la maison)

dotnet tool install --global Evolve.Tool 


3) Mettre à jour pour la version prerelease qui fonctionne avec .Net 8.0

dotnet tool update evolve.tool -g --prerelease


4) Migration

evolve migrate sqlserver -c "Data Source=LLBINFD062013;Initial Catalog=BD4D5_Pays_Monde;Integrated Security=True;Persist Security Info=False;Pooling=False;Multiple Active Result Sets=False;Encrypt=False;Trust Server Certificate=False;Command Timeout=0" -s Geographie -s Caracteristique -s Clients --target-version 1.5


5) Scaffold

dotnet ef dbcontext scaffold Name=BD4D5_Pays_Monde Microsoft.EntityFrameworkCore.SqlServer -o Models --context-dir Data --context BD4D5_Pays_MondeContext --data-annotations --force
